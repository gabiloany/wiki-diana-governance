# Agentes de Tratamento

Este capítulo apresenta quem são os responsáveis pelo tratamento de dados pessoais, conforme a LGPD. Entender ‘quem faz o quê’ é essencial para garantir o uso correto das informações, proteger os direitos dos cidadãos e manter as atividades em conformidade com a lei (BRASIL, 2022). De forma simples, há três papéis principais em que o Controlador é quem decide como e para que os dados serão utilizados. O Operador é quem executa essas ações, tratando os dados conforme as orientações do Controlador. Já o Encarregado pelo tratamento de dados pessoais atua como ponto de contato, facilitando a comunicação entre a instituição, os cidadãos e a Autoridade Nacional de Proteção de Dados (ANPD). Quando esses papéis estão bem definidos, o trabalho fica mais organizados e transparente. Além disso, essa organização fortalece a governança de dados, ajuda a evitar erros e garante que as informações sejam tratadas de forma segura, responsável e alinhadas às necessidades (DAMA, 2017).

O Prontuário Eletrônico e-SUS APS apresenta, em seu termo de uso, uma estrutura clara e orientativa sobre os papéis do Controlador, Operador e do Encarregado. Essas definições ajudam a compreender como se organizam as responsabilidades no uso das informações. Neste contexto, a intenção é apresentar a seguir, de forma objetiva, os principais papéis mencionados no termo.

## Segundo as definições do Termo de Uso do Prontuário Eletrônico e-SUS APS

### Controlador

A Lei Geral de Proteção de Dados Pessoais define como controlador, em seu Art. 5º, inciso VI, a pessoa natural ou jurídica, de direito público ou privado, a quem competem as decisões referentes ao tratamento de dados pessoais. Além disso, a Autoridade Nacional de Proteção de Dados (ANPD) esclarece a distinção entre controladoria conjunta em decisões comuns — quando duas ou mais entidades compartilham a mesma intenção sobre finalidades e meios do tratamento e decidem em conjunto — e decisões convergentes, nas quais decisões distintas se complementam a ponto de o tratamento não ser viável sem a participação de ambos os controladores (Guia Orientativo para Definições dos Agentes de Tratamento de Dados Pessoais e do Encarregado, publicado pela ANPD, pg. 14).

Para o Prontuário Eletrônico e-SUS APS, as decisões referentes ao tratamento de dados pessoais são de responsabilidade tanto do Ministério da Saúde, quanto dos municípios que aderem à respectiva estratégia, ou mesmo, quando for o caso, dos estados, exercendo, dessa forma, controladoria conjunta, uma vez que possuem poder de decisão sobre o tratamento de dados pessoais, há interesse mútuo, com base em finalidades próprias, sobre um mesmo tratamento e tomam decisões comuns ou convergentes sobre as finalidades e elementos essenciais do tratamento.

### Operador

A Lei Geral de Proteção de Dados Pessoais define como operador, em seu Art. 5º, inciso VII, a pessoa natural ou jurídica, de direito público ou privado, que realiza o tratamento de dados pessoais em nome do controlador. ### Encarregado

A Lei Geral de Proteção de Dados Pessoais define como encarregado, em seu Art. 5º, inciso VIII, a pessoa indicada pelo controlador e operador para atuar como canal de comunicação entre o controlador, os titulares dos dados e a Autoridade Nacional de Proteção de Dados (ANPD). ## Formalização dos papéis no âmbito municipal

Com o objetivo de fortalecer a governança de dados no âmbito municipal e promover a adoção de boas práticas no tratamento de informações pessoais, este documento propõe a definição formal de papéis e responsabilidade relacionados ao uso de dados, inspirados no modelo adotado pelo Termo de Uso do Prontuário Eletrônico e-SUS APS.

Para fins deste documento, recomenda-se que o município institua, de forma clara, os papéis de Controlado, Operador e o Encarregado pelo tratamento de dados pessoais, cabendo ao Comitê Estratégico designar os responsáveis por cada uma dessas funções, conforme estrutura organizacional.

De forma geral, propõem-se:

O Controlador será o responsável por definir como e para que os dados pessoais serão utilizados;

O Operador será quem realizará o tratamento dos dados, seguindo as orientações do Controlador;

O Encarregado, atuará como ponto de contato entre o município, os cidadãos e a ANPD.

A formalização desses papéis no contexto municipal ajudará a organizar as responsabilidades, aumentar a transparência das ações e garantirá que as decisões sobre os dados pessoais sejam tomadas com responsabilidade e segurança, contribuindo para a adoção e a disseminação das boas práticas de forma mais eficiente (Brasil, 2018).
