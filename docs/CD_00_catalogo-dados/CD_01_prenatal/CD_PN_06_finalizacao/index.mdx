# 2.6 Finalização do Atendimento

A seção **Finalização do Atendimento** reúne os campos utilizados para concluir e registrar o encerramento do atendimento no Prontuário Eletrônico e-SUS APS. Nesta página é apresentado o mapeamento técnico desses campos, permitindo identificar sua correspondência com a estrutura do banco de dados utilizada pelo sistema.

### 2.6.1 Mapeamento Técnico dos Campos do Sistema

Os quadros a seguir apresentam o mapeamento dos campos da área de Finalização do Atendimento, indicando seu destino no banco de dados do Prontuário Eletrônico e-SUS APS. Para cada tabela, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.

Quando o campo **Cidadão participou do atendimento** é marcado, o sistema exibe a opção **Forma de participação**, na qual é possível especificar de que maneira o cidadão participou do atendimento (presencial, remoto, entre outras).
