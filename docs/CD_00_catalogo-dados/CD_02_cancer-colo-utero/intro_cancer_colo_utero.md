# Rastreamento do Câncer do Colo do Útero

A linha de cuidado **Rastreamento do Câncer do Colo do Útero** contempla o conjunto de informações registradas durante o atendimento de rastreamento e acompanhamento no Prontuário Eletrônico e-SUS APS. Esta documentação apresenta o mapeamento técnico dos principais formulários utilizados durante o atendimento, relacionando os campos exibidos na interface do sistema às respectivas tabelas e colunas do banco de dados.

O objetivo deste catálogo é apoiar atividades de governança de dados, integração de sistemas, desenvolvimento de soluções analíticas e compreensão da estrutura de armazenamento das informações do Prontuário Eletrônico e-SUS APS.

A documentação está organizada conforme o fluxo do atendimento realizado no sistema, abrangendo os seguintes módulos:

- [Cadastro](/CD_00_catalogo-dados/CD_02_cancer-colo-utero/CD_CCU_01_cadastro)
- [Objetivo](/CD_00_catalogo-dados/CD_02_cancer-colo-utero/CD_CCU_02_objetivo)
- [Plano](/CD_00_catalogo-dados/CD_02_cancer-colo-utero/CD_CCU_03_plano)

Cada seção apresenta imagens da interface do sistema acompanhadas pelo respectivo mapeamento técnico dos campos e suas correspondências no banco de dados.
