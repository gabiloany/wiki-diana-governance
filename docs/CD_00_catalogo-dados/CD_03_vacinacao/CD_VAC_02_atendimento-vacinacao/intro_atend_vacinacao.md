# Atendimento de Vacinação

O **Atendimento de Vacinação** contempla o conjunto de informações registradas durante o atendimento específico de vacinação no Prontuário Eletrônico e-SUS APS, iniciado a partir da **Lista de atendimentos** com o serviço **Vacina** selecionado. Esta documentação apresenta o mapeamento técnico dos principais formulários utilizados durante o registro de doses, relacionando os campos exibidos na interface do sistema às respectivas tabelas e colunas do banco de dados.

O objetivo deste catálogo é apoiar atividades de governança de dados, integração de sistemas, desenvolvimento de soluções analíticas e compreensão da estrutura de armazenamento das informações do Prontuário Eletrônico e-SUS APS.

A documentação está organizada conforme as seções da tela de atendimento de vacinação, abrangendo os seguintes módulos:

- [Condições](/CD_00_catalogo-dados/CD_03_vacinacao/CD_VAC_02_atendimento-vacinacao/CD_VAC_01_vacinacao/)
- [Calendário Vacinal do Adulto](/CD_00_catalogo-dados/CD_03_vacinacao/CD_VAC_02_atendimento-vacinacao/CD_VAC_02_calendario/)
- [Outras Doses e Imunobiológicos](/CD_00_catalogo-dados/CD_03_vacinacao/CD_VAC_02_atendimento-vacinacao/CD_VAC_03_imunobiologico/)

Cada seção apresenta imagens da interface do sistema acompanhadas pelo respectivo mapeamento técnico dos campos e suas correspondências no banco de dados.
