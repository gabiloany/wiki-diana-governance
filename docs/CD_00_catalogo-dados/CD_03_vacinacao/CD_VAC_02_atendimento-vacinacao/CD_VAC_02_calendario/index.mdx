# 2.14 Calendário Vacinal do Adulto

A seção **Calendário Vacinal do Adulto** apresenta as vacinas recomendadas para a faixa etária adulta e a situação de cada dose do cidadão, como aplicada, atrasada, disponível ou futura. A partir dela, o profissional pode aplicar uma dose, aprazar a próxima ou transcrever doses registradas na caderneta de vacinação.

### 2.14.1 Calendário nacional completo

Por padrão, o calendário exibe apenas os imunobiológicos recomendados para o cidadão. Ao selecionar a opção <ImagemInline src="/img/vacinacao/mostrar-vazio.png" alt="Mostrar calendário nacional completo" />, o sistema expande a exibição e apresenta todos os imunobiológicos previstos no calendário nacional, incluindo aqueles ainda não iniciados.

No topo do calendário, o menu expansível **Doses/imunobiológicos/vacinas para COVID-19 | COV19** reúne as vacinas de COVID-19 do cidadão. Por padrão, o menu é exibido recolhido.

### 2.14.6 Aplicar

Para registrar a aplicação da dose durante o atendimento, utiliza-se a opção <ImagemInline src="/img/vacinacao/aplicar-inline.png" alt="Aplicar" />, que abre o formulário de **Aplicação de imunobiológico**, com os dados de estratégia, grupo de atendimento, lote, fabricante, via de administração, local de aplicação, motivo de indicação, profissional prescritor e observações.
