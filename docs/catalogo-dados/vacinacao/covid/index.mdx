# 13. Doses/Imunobiológicos/Vacinas para COVID-19 | COV19

A subseção **Vacinas para COVID-19** é exibida de forma suprimida (recolhida) por padrão ao acessar a aba de Vacinação, agrupando as doses de imunobiológicos contra a COVID-19 aplicadas ao cidadão.

<Figura
  src="/img/vacinacao/covid_suprimido.png"

/>

Ao expandir o bloco, é possível visualizar as informações detalhadas sobre o histórico de doses aplicadas, organizadas por imunobiológico contra a COVID-19.

<Figura
  src="/img/vacinacao/covid_expand.png"

/>
