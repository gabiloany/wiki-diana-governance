# 9. Objetivo

A seção **Objetivo** reúne os registros dos achados clínicos e dos resultados de exames obtidos durante o atendimento, permitindo o acompanhamento dos exames laboratoriais realizados pelo cidadão.

### 9.1 Mapeamento Técnico dos Campos do Sistema

As tabelas a seguir apresentam o mapeamento dos campos da área de Objetivo, indicando sua origem no banco de dados do Prontuário Eletrônico. Para cada tabela, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.

### 9.2 Resultado de Exames

Ao selecionar <ImagemInline src="/img/cancer/objetivo/resultados_exames_inline.png" alt="+ Adicionar resultados de exames" />, é exibida uma tela de inserção de dados, na qual é possível registrar os resultados de exames laboratoriais realizados pelo cidadão.
