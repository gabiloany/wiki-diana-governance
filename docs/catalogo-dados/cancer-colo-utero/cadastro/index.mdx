# 8. Cadastro

A seção **Cadastro** reúne os dados pessoais do cidadão que servem de base para o rastreamento de câncer do colo do útero, contemplando informações como data de nascimento, sexo e identidade de gênero. Nesta página é apresentado o caminho de acesso ao cadastro do cidadão no Prontuário Eletrônico e-SUS APS, bem como o mapeamento técnico dos campos utilizados.

### 8.1 Acesso ao cadastro do cidadão

Para acessar o cadastro do cidadão, é necessário selecionar a opção **Cidadão** no menu lateral do Prontuário Eletrônico e-SUS APS.

<Figura
  src="/img/cancer/cadastro/cidadao.png"
  alt="Menu lateral - Opção Cidadão"
  numero={1}

  fonte="Prontuário Eletrônico e-SUS APS - Versão 5.5.6"
/>

Ao selecionar essa opção, o sistema exibe a tela de busca de cadastros, na qual é possível pesquisar cidadãos já cadastrados na base local ou na base nacional, além de adicionar um novo cidadão por meio do botão **Adicionar cidadão**.

/>

### 8.2 Dados pessoais

Ao adicionar um novo cidadão, é exibido o formulário de **Cadastro do cidadão**. Para fins do rastreamento de câncer do colo do útero, interessam três campos específicos desse formulário: **Data de nascimento**, **Sexo** e **Qual identidade de gênero?**.

<Figura
  src="/img/cancer/cadastro/dn_sexo.png"
  alt="Formulário de Cadastro do Cidadão - Dados Pessoais"
  numero={3}
  descricao="Tela de Cadastro do Cidadão - Campos Data de Nascimento e Sexo no Prontuário Eletrônico e-SUS APS"
  fonte="Prontuário Eletrônico e-SUS APS - Versão 5.5.6"
/>

Ao final do formulário, o sistema pergunta se o cidadão deseja informar sua identidade de gênero.

<Figura
  src="/img/cancer/cadastro/id_genero.png"
  alt="Pergunta sobre identidade de gênero"
  numero={4}
  descricao="Tela de Cadastro do Cidadão - Pergunta sobre Identidade de Gênero no Prontuário Eletrônico e-SUS APS"
  fonte="Prontuário Eletrônico e-SUS APS - Versão 5.5.6"
/>

Ao selecionar **Sim**, o sistema exibe a lista de opções disponíveis para identidade de gênero, incluindo homem transgênero, mulher transgênero, travesti, homem cisgênero, mulher cisgênero, não-binário e outro.

<Figura

/>
