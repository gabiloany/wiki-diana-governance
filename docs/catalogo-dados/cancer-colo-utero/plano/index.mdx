# 10. Plano

A seção **Plano** reúne as ações definidas pelo profissional de saúde para a condução do atendimento, contemplando a solicitação de exames e procedimentos ao cidadão.

### 10.1 Mapeamento Técnico dos Campos do Sistema

Os quadros a seguir apresentam o mapeamento dos campos da área de Plano, indicando seu destino no banco de dados do Prontuário Eletrônico e-SUS APS. Para cada quadro, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.

### 10.2 Solicitação de Exames

A seção **Solicitação de Exames** concentra as funcionalidades para requisição de exames e procedimentos ao cidadão, organizada em três subdivisões: Adicionar exame comum, Adicionar exame de alto custo e Adicionar OCI (Outros Cuidados e/ou Intervenções), detalhadas nas subseções a seguir.
