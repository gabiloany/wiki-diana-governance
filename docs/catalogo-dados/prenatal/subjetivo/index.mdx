# 3. Subjetivo

A seção **Subjetivo** concentra as informações relatadas pelo cidadão durante o atendimento, registradas pelo profissional de saúde no Prontuário Eletrônico. Nesta página é apresentado o mapeamento técnico dos campos disponíveis na interface do sistema, relacionando cada elemento visual às respectivas tabelas e colunas do banco de dados.

### 3.1 Mapeamento Técnico dos Campos do Sistema

As tabelas a seguir apresentam o mapeamento dos campos da área de Subjetivo, indicando sua origem no banco de dados do Prontuário Eletrônico. Para cada tabela, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.
