# 3. Subjetivo

A seção **Subjetivo** concentra as informações relatadas pelo cidadão durante o atendimento, registradas pelo profissional de saúde no Prontuário Eletrônico e-SUS APS. Nesta página é apresentado o mapeamento técnico dos campos disponíveis na interface do sistema, relacionando cada elemento visual às respectivas tabelas e colunas do banco de dados.

### 3.1 Mapeamento Técnico dos Campos do Sistema

Os quadros a seguir apresentam o mapeamento dos campos da área de Subjetivo, indicando seu destino no banco de dados do Prontuário Eletrônico e-SUS APS. Para cada quadro, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.

### 3.2 Motivo da Consulta (CIAP 2)

Ao buscar o motivo da consulta no campo **Motivo da consulta (CIAP 2)**, o sistema exibe uma lista de sugestões contendo o código CIAP correspondente, além das descrições dos critérios de inclusão e exclusão de cada classificação, auxiliando o profissional na seleção do código mais adequado.

<Figura
  src="/img/prenatal/subjetivo/motivo_consulta.png"

  numero={2}
  descricao="Tela de Subjetivo - Busca do Motivo da Consulta (CIAP 2) no Prontuário Eletrônico e-SUS APS"
  fonte="Prontuário Eletrônico e-SUS APS - Versão 5.5.6"
/>

Após selecionado, o motivo da consulta é adicionado a uma lista, disponibilizando os ícones de edição e exclusão para o gerenciamento do registro.
