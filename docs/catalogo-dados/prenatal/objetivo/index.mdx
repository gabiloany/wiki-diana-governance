# 4. Objetivo

A seção **Objetivo** contempla os dados observados ou coletados durante o atendimento, incluindo exame físico, anexo de arquivos, medições clínicas, consumo alimentar, vacinação e resultados de exames. Nesta página são apresentados os campos disponíveis na interface do Prontuário Eletrônico e seu respectivo mapeamento para a estrutura do banco de dados, permitindo identificar onde cada informação é armazenada.

### 4.1 Mapeamento Técnico dos Campos do Sistema

As tabelas a seguir apresentam o mapeamento dos campos da área de Objetivo, indicando sua origem no banco de dados do Prontuário Eletrônico. Para cada tabela, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.

### 4.6 Marcadores de consumo alimentar

O bloco **Marcadores de consumo alimentar** é um grupo expansível que reúne o questionário de Marcadores de Consumo Alimentar (MCA) do SISVAN, com perguntas segmentadas por faixa etária (crianças menores de 2 anos, crianças com 2 anos ou mais, adolescentes, adultos e gestantes), abordando o consumo de alimentos in natura e ultraprocessados, além de hábitos como assistir TV durante as refeições e a adição de sal.
