# 4. Objetivo

A seção **Objetivo** contempla os dados observados ou coletados durante o atendimento, incluindo medições clínicas, consumo alimentar e resultados de exames. Nesta página são apresentados os campos disponíveis na interface do Prontuário Eletrônico e seu respectivo mapeamento para a estrutura do banco de dados, permitindo identificar onde cada informação é armazenada.

### 4.1 Mapeamento Técnico dos Campos do Sistema

As tabelas a seguir apresentam o mapeamento dos campos da área de Objetivo, indicando sua origem no banco de dados do Prontuário Eletrônico. Para cada tabela, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.
