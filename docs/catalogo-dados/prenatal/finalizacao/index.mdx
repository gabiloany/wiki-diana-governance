# 7. Finalização do Atendimento

A seção **Finalização do Atendimento** reúne os campos utilizados para concluir e registrar o encerramento do atendimento no Prontuário Eletrônico. Nesta página é apresentado o mapeamento técnico desses campos, permitindo identificar sua correspondência com a estrutura do banco de dados utilizada pelo sistema.

### 7.1 Mapeamento Técnico dos Campos do Sistema

As tabelas a seguir apresentam o mapeamento dos campos da área de Finalização do Atendimento, indicando sua origem no banco de dados do Prontuário Eletrônico. Para cada tabela, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.
