# 5. Avaliação

A seção **Avaliação** reúne os registros clínicos relacionados às condições avaliadas durante o atendimento, abrangendo problemas e condições de saúde, informações específicas de pré-natal e alergias do cidadão. Esta documentação apresenta o mapeamento técnico entre os campos exibidos na interface do Prontuário Eletrônico e-SUS APS e sua representação no banco de dados.

### 5.1 Mapeamento Técnico dos Campos do Sistema

Os quadros a seguir apresentam o mapeamento dos campos da área de Avaliação, indicando seu destino no banco de dados do Prontuário Eletrônico e-SUS APS. Para cada quadro, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.

### 5.3 Problemas e/ou Condições Avaliados Neste Atendimento

Além do campo de impressões gerais, o sistema disponibiliza o formulário de **Problemas e/ou condições avaliados neste atendimento**, no qual é possível pesquisar problemas/condições já registrados ou cadastrar um novo a partir dos códigos CIAP 2 e CID 10.

<Figura
  src="/img/prenatal/avaliacao/ciap2.png"

/>

Ao selecionar o termo **GRAVIDEZ** da lista de sugestões, o sistema preenche automaticamente o código CID 10 correspondente, permitindo complementar o cadastro do problema/condição antes de adicioná-lo.

### 5.4 Pré-natal

Quando o problema/condição informado corresponde a um código de gravidez e o botão de adicionar é acionado, o sistema habilita o bloco de **Pré-natal, parto e nascimento**, com campos específicos de acompanhamento gestacional, como tipo de gravidez, altura uterina, risco de gravidez, edema, movimentação fetal e batimento cardíaco fetal.

### 5.5 Alergias e Reações Adversas

Abaixo do formulário de Problemas e/ou condições, a guia Avaliação disponibiliza o bloco expansível **Alergias e reações adversas**, que permite pesquisar as alergias já registradas para o cidadão e, ao ser expandido, exibe o formulário completo para o cadastro de uma nova ocorrência.

<Figura
  src="/img/prenatal/avaliacao/adversas.png"

  fonte="Prontuário Eletrônico e-SUS APS - Versão 5.5.6"
/>

#### 5.5.1 Adicionar Alergia e Reação Adversa

Ao expandir o bloco, é exibido o formulário completo de cadastro, contemplando a categoria e o agente causador, o tipo de reação, a criticidade, o grau de certeza, as manifestações apresentadas, a data ou idade de início e observações complementares.
