# 5. Avaliação

A seção **Avaliação** reúne os registros clínicos relacionados às condições avaliadas durante o atendimento, abrangendo problemas e condições de saúde, informações específicas de pré-natal e alergias do cidadão. Esta documentação apresenta o mapeamento técnico entre os campos exibidos na interface do Prontuário Eletrônico e sua representação no banco de dados.

### 5.1 Mapeamento Técnico dos Campos do Sistema

As tabelas a seguir apresentam o mapeamento dos campos da área de Avaliação, indicando sua origem no banco de dados do Prontuário Eletrônico. Para cada tabela, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.
