# 2.5 Plano

A seção **Plano** contempla as ações definidas pelo profissional de saúde para a condução do atendimento, incluindo prescrições, solicitações de exames, emissão de atestados, orientações e encaminhamentos. Nesta página é apresentado o mapeamento técnico de cada funcionalidade, relacionando os campos da interface do Prontuário Eletrônico e-SUS APS às respectivas tabelas e colunas do banco de dados.

### 2.5.1 Mapeamento Técnico dos Campos do Sistema

Os quadros a seguir apresentam o mapeamento dos campos da área de elaboração do Plano, indicando seu destino no banco de dados do Prontuário Eletrônico e-SUS APS. Para cada quadro, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.
