# Pré-Natal

A linha de cuidado **Pré-Natal** contempla o conjunto de informações registradas durante o acompanhamento da gestante no Prontuário Eletrônico do e-SUS APS. Esta documentação apresenta o mapeamento técnico dos principais formulários utilizados durante o atendimento, relacionando os campos exibidos na interface do sistema às respectivas tabelas e colunas do banco de dados.

O objetivo deste catálogo é apoiar atividades de governança de dados, integração de sistemas, desenvolvimento de soluções analíticas e compreensão da estrutura de armazenamento das informações do Prontuário Eletrônico.

A documentação está organizada conforme o fluxo do atendimento realizado no sistema, abrangendo os seguintes módulos:

- [Antecedentes](/catalogo-dados/prenatal/antecedentes/)
- [Subjetivo](/catalogo-dados/prenatal/subjetivo/)
- [Objetivo](/catalogo-dados/prenatal/objetivo/)
- [Avaliação](/catalogo-dados/prenatal/avaliacao/)
- [Plano](/catalogo-dados/prenatal/plano/)
- [Finalização do Atendimento](/catalogo-dados/prenatal/finalizacao/)

Cada seção apresenta imagens da interface do sistema acompanhadas pelo respectivo mapeamento técnico dos campos e suas correspondências no banco de dados.
