# 2. Antecedentes

A seção **Antecedentes** reúne informações relacionadas ao histórico clínico e familiar do cidadão, contemplando registros sobre parto e nascimento, problemas e condições resolvidos, além dos antecedentes familiares cadastrados no Prontuário Eletrônico. Nesta página são apresentados o mapeamento técnico dos campos exibidos na interface do sistema e sua correspondente estrutura no banco de dados, facilitando a identificação da origem e do armazenamento de cada informação.

### 2.1 Mapeamento Técnico dos Campos do Sistema

As tabelas a seguir apresentam o mapeamento dos campos da área de Antecedentes, indicando sua origem no banco de dados do Prontuário Eletrônico. Para cada tabela, são disponibilizadas imagens extraídas diretamente da interface do sistema, com o objetivo de facilitar a identificação visual dos campos na plataforma.
